# Profile Distribution Docs Update Checklist

Use when a Software Factory profile distribution changes.

## Distribution metadata

- distribution/release identifier:
- affected profiles/roles:
- public repo/package links:
- public communication approved: yes | no | pending

## Content updates

- [ ] README/install instructions updated.
- [ ] Role/SOUL guidance summarized accurately.
- [ ] Required skills/templates list updated.
- [ ] Least-privilege and mutation authority boundaries updated.
- [ ] Migration/update notes included.
- [ ] Changelog/release notes updated.
- [ ] Contribution guidance reflects source-of-truth vs generated repo policy.

## Safety checks

- [ ] Generated docs exclude secrets, local state, memories, sessions, logs, Kanban DB/workspaces, and private sprite metadata.
- [ ] Public examples use placeholders, not live private operational values.
- [ ] Any publication/push requires separate approval.
