# Docs Freshness Checklist

Use after each release or profile distribution update.

- [ ] Overview reflects current public value proposition and v0/future boundary.
- [ ] Architecture page reflects current public role model without operational inventory.
- [ ] Profiles and roles page lists public responsibilities and mutation boundaries.
- [ ] Kanban workflow page reflects current evidence and review loop.
- [ ] Observability/skill-locality page reflects current public architectural constraints.
- [ ] Profile distributions page reflects current install/update/contribution model.
- [ ] Release notes/changelog include this release.
- [ ] Safety/public-site hygiene page reflects current redaction policy.
- [ ] Links/routes build and resolve in preview.
- [ ] Public-safety validation script passes or documented exceptions are reviewed.
